# GetDL Web

Web wrapper mobile-friendly untuk API `getdl.space`.

## Jalankan lokal

```bash
npm install
npm start
```

Buka `http://localhost:3000`.

## Deploy

Project ini membutuhkan hosting yang dapat menjalankan **Node.js**, bukan GitHub Pages statis.

Upload seluruh isi project, lalu jalankan:

```bash
npm install
npm start
```

Set `PORT` jika provider hosting memberikan port melalui environment variable.

## Catatan

Backend meneruskan URL dari pengguna ke endpoint API yang ada pada script awal. Pastikan penggunaan layanan/API dan materi yang diunduh sesuai izin serta ketentuan platform terkait.
